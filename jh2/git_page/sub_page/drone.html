Passive Drone Detection with COTS mmWave

Goal: detect small consumer drones opportunistically using commodity mmWave radios and beam patterns (no active radar).

#passive-sensing #mmwave #beamforming #rf-fingerprinting #knn

Summary

92.4% accuracy

KNN classification using top-6 receiver-antenna amplitude indices under quasi‑omnidirectional receive pattern.

≈ 5° error

Non‑LOS angle estimation error using relationship between predefined beam patterns and received SNR.

Passive operation

Leverages ambient transmissions; detects drone‑induced beam pattern changes caused by rotor vibration (frequency & phase).

System Overview

Problem

Small drones often evade conventional radar due to their low radar cross section and complex micro‑Doppler signatures. We target a passive solution using commodity mmWave (COTS) devices.

Key Idea

Drone rotor vibration perturbs the reflected beam pattern. These perturbations shift which receiver antennas have the highest amplitudes, producing a robust pattern usable as a fingerprint.

Sensing Modalities

  • Receiver antenna index pattern: sort receive antennas by amplitude; use top‑k indices as features.
  • Beam/SNR relation: map predefined transmit/receive beam weights (complex) to measured channel/SNR to estimate AoA.
  • Temporal signature: iFFT / time‑domain analysis to capture periodic vibration effects.

We avoid specialized hardware by using available beam codebooks and channel measurements in COTS devices.

Signal Processing Pipeline

  1. Acquisition: Sweep over predefined beam patterns; record complex channel status R_s per beam/antenna.
  2. Pre‑conditioning: Normalize amplitude/phase; optional denoising; form antenna amplitude matrix.
  3. Time‑domain view: Apply iFFT on selected subcarriers to expose periodic components from rotor vibration.
  4. Feature extraction: (a) Top‑k antenna indices; (b) beam–SNR relation statistics; (c) vibration frequency estimate.
  5. Inference: K‑Nearest Neighbors for detection; AoA via beam pattern–SNR matching.

Receiver Antenna Pattern Classification

Feature: Top‑6 Receiver Antenna Indices

  • Receiver uses quasi‑omnidirectional pattern.
  • From each snapshot, collect the six highest‑amplitude antenna indices.
  • Induced by drone vibration, the identity/order of top‑k indices changes in a class‑specific way.

Classifier: KNN (Hamming distance over index tuples). Reported accuracy: 92.4%.

Angle (AoA) Estimation

Beam/SNR Relationship

Let A be the complex predefined beam weights and R_s the measured complex channel per beam. The received SNR varies systematically with the beam steered angle. We search for the AoA that maximizes a similarity score between A(θ) and R_s.

  • 3 geometry cases: object near station; mid‑point; near AP.
  • Reported non‑LOS angle error ≈ 5°.

Estimator Sketch

def estimate_aoa(A_codebook, R_meas, thetas):
    # A_codebook: dict[theta] -> complex weight vector
    # R_meas: measured complex response vector
    best_theta, best_score = None, -1e9
    for th in thetas:
        score = real(dot(conj(A_codebook[th]), R_meas)) / (norm(A_codebook[th]) * norm(R_meas) + 1e-9)
        if score > best_score:
            best_theta, best_score = th, score
    return best_theta

Alternative scores: magnitude correlation, phase‑aware cosine similarity, or learned mapping.

Experiments & Results

Setup

  • COTS mmWave devices with beam codebook support.
  • Receiver in quasi‑omni mode; sweep across beams.
  • Collect complex channel per beam/antenna snapshot.

Detection

Top‑6 index features + KNN → 92.4% accuracy. Robust to low‑/high‑speed vibration conditions.

Result Consistent class separation via antenna index permutations.

Localization

Beam/SNR relation yields AoA with ≈ 5° error in NLOS scenarios across three spatial cases.

Note Error is geometry‑dependent; multipath may increase bias.

Discussion

Strengths

  • Passive: no dedicated radar transmitter required.
  • Commodity hardware: leverages existing beam codebooks and CSI.
  • Simple features: antenna index tuples are lightweight and privacy‑preserving.

Limitations & Next Steps

  • Multipath sensitivity: index patterns can shift due to environmental changes.
  • Generalization: evaluate across devices, environments, and multiple drone models.
  • Fusion: combine index features with Doppler‑like temporal cues and phase statistics.
  • Learning: replace KNN with a compact sequence model for improved robustness.
Reproducibility Tip: Log raw complex snapshots (per beam/antenna), store the top‑k index vectors and vibration features, and keep a simple JSON manifest (setup, geometry, labels) for quick ablations.
